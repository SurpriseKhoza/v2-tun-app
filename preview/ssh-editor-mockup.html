SSH EDITOR CONCEPT

Simple on the surface. Powerful underneath.

The editor exposes only the choices users understand: SSH credentials, connection method, and routing. WS/WSS implementation details remain internal.

Design decision
Direct SSH, HTTP payload, TLS/SNI, Proxy, and DNS tunnel are user-facing modes. WebSocket is not a visible field or transport selector.
